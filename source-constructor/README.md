## 💡 О продукте

**Source Constructor** — это AI-companion, который проводит глубокие диалоговые сессии (Discovery Sessions) для выявления истинных желаний пользователя, а затем автоматически генерирует структурированные проекты с пошаговым планом реализации.

### Ключевая ценность
- **Проблема:** 92% людей ставят цели, которые не отражают их истинные желания
- **Решение:** AI-диалог + структурированная генерация проектов
- **Результат:** Пользователь знает ЧТО делать, ЗАЧЕМ и КАК

### Целевая аудитория
- Молодые профессионалы 25–38 лет
- Люди на карьерном переходе
- Предприниматели на ранней стадии
- Люди, работающие с коучами / терапевтами
