# Source Constructor (SOC) — Customer Journey Maps

**Document Version:** 1.0
**Last Updated:** 2026-03-02
**Status:** Approved
**Owner:** Research Lead

---

## Overview

This document maps the end-to-end experience of SOC users across two primary journeys:

1. **Acquisition & Onboarding Journey** — From first awareness to first "aha moment"
2. **Core Product Journey** — From first Discovery Session to consistent usage

Each journey is mapped across:
- **Phases** — Key stages of the journey
- **Actions** — What the user does
- **Thoughts** — What the user is thinking
- **Feelings** — Emotional state (1 = very negative, 5 = very positive)
- **Pain Points** — Where friction occurs
- **Opportunities** — Where SOC can add value

---

## Journey 1: Acquisition & Onboarding

### Persona: Alex, 31 — The Stuck Professional

---

### Phase 1: Awareness

**Trigger:** Alex reads an article on IndieHackers about "why most side projects fail before they start." The author mentions Source Constructor as a tool they used to get clarity.

| Dimension | Detail |
|-----------|--------|
| **Actions** | Clicks link to SOC website; reads landing page; skims features |
| **Thoughts** | "This sounds interesting… but is this just another generic productivity tool?" |
| **Feelings** | Curious but skeptical (3/5) |
| **Pain Point** | Unclear differentiation from journaling apps or life coaching |
| **Opportunity** | Landing page must immediately convey: *"We help you discover what you TRULY want — not just what sounds good"* |

---

### Phase 2: Consideration

**Trigger:** Alex watches a 90-second demo video showing a Discovery Session. He hears an AI ask: *"You mentioned you love systems. If you could design a system that solved a problem you personally face, what would it be?"*

| Dimension | Detail |
|-----------|--------|
| **Actions** | Watches demo video; reads user testimonials; checks pricing page |
| **Thoughts** | "That question is actually really interesting. I'd never thought of it that way." |
| **Feelings** | Intrigued, slightly excited (4/5) |
| **Pain Point** | Pricing page is unclear — what does free tier include? |
| **Opportunity** | Demo video must show a genuine, deep conversation — not surface-level. Testimonials should focus on transformation ("I finally knew what to build") not features |

---

### Phase 3: Sign-Up

**Trigger:** Alex clicks "Try Free for 7 Days" and begins sign-up.

| Dimension | Detail |
|-----------|--------|
| **Actions** | Fills in email, password; answers 3 onboarding questions about current situation |
| **Thoughts** | "These questions are pretty thoughtful — they're not asking me what tools I use." |
| **Feelings** | Slightly cautious, slightly hopeful (3.5/5) |
| **Pain Point** | If onboarding asks too many questions, Alex will drop off. Maximum 3 questions |
| **Opportunity** | The onboarding survey frames SOC as different from the start: questions should feel like the beginning of a conversation, not a form |

---

### Phase 4: First Discovery Session

**Trigger:** Alex lands on the dashboard and sees a clear CTA: "Start Your First Discovery Session."

| Dimension | Detail |
|-----------|--------|
| **Actions** | Clicks CTA; reads session intro; begins responding to AI |
| **Thoughts** | "This AI is asking better questions than my therapist asked last month. Why?" |
| **Feelings** | Engaged, slightly vulnerable (4/5) |
| **Pain Point** | If Alex gives a surface answer, the AI needs to push gently. Shallow sessions produce shallow output |
| **Opportunity** | The AI's first 3 questions determine everything. Must be designed for depth without feeling like an interrogation |

---

### Phase 5: Session End & Project Generation

**Trigger:** Session concludes after 20–35 minutes. Alex is shown a summary and a generated project.

| Dimension | Detail |
|-----------|--------|
| **Actions** | Reads AI-generated session summary; views project structure; optionally edits |
| **Thoughts** | "This is actually me. How did it know to frame it as a 'knowledge-sharing platform'?" |
| **Feelings** | Surprised, excited, validated (4.5/5) |
| **Pain Point** | If the project feels generic ("Start a blog"), trust collapses immediately |
| **Opportunity** | The generated project must feel personal. Reference specific language Alex used in the session |

---

### Phase 6: The "Aha Moment"

**Definition of Aha Moment:** Alex shares the project with a friend and says, *"I finally know what I'm actually building."*

**Timeline target:** Aha moment must occur within the first session

| Dimension | Detail |
|-----------|--------|
| **Actions** | Screenshots or shares the project; adds tasks to the roadmap |
| **Thoughts** | "I've wanted clarity on this for months. I got it in 30 minutes." |
| **Feelings** | Excited, empowered, grateful (5/5) |
| **Pain Point** | If clarity doesn't feel immediately actionable, energy dissipates |
| **Opportunity** | Immediately after project generation: surface "Your first task" — one specific, achievable action for today |

## Journey 2: Core Product Loop (Post-Onboarding)

### Persona: Alex — Week 2 onward

---

### Phase 1: Daily Check-In

**Context:** Alex has completed 2 Discovery Sessions and has an active project. It's Tuesday morning.

| Dimension | Detail |
|-----------|--------|
| **Actions** | Opens SOC app; sees daily check-in prompt; answers 2 quick questions about yesterday |
| **Thoughts** | "This is low effort. I can do this in 3 minutes." |
| **Feelings** | Neutral to positive (3.5/5) |
| **Pain Point** | If check-ins feel repetitive or robotic, Alex will start ignoring them |
| **Opportunity** | Check-in questions should reference recent session content: "Yesterday you said you'd [specific task]. How did it go?" |

---

### Phase 2: Weekly Progress Review

**Context:** Alex receives a weekly summary email every Sunday evening.

| Dimension | Detail |
|-----------|--------|
| **Actions** | Opens email; reads summary of the week's check-ins and progress |
| **Thoughts** | "I did more than I thought this week. The data doesn't lie." |
| **Feelings** | Proud, motivated (4/5) |
| **Pain Point** | If progress feels invisible, motivation fades |
| **Opportunity** | Weekly email should show a "consistency streak," completed tasks, and one insight pulled from the week's check-ins |

---

### Phase 3: Discovery Session #2

**Context:** Alex is stuck on a specific decision — *"Should I build for developers or non-technical users first?"*

| Dimension | Detail |
|-----------|--------|
| **Actions** | Starts a new Discovery Session, entering a specific question as context |
| **Thoughts** | "I want to get unstuck on this specific thing, not do a full session." |
| **Feelings** | Focused, slightly impatient (3/5) |
| **Pain Point** | Open-ended Discovery Sessions feel too broad after the first one |
| **Opportunity** | Session types: "Open Discovery" (general exploration) vs. "Focused Session" (specific question) |

---

### Phase 4: Hitting a Milestone

**Context:** Alex completes the first version of his landing page — a milestone from his SOC project plan.

| Dimension | Detail |
|-----------|--------|
| **Actions** | Marks milestone as complete; sees celebration animation; AI sends a congratulatory message |
| **Thoughts** | "That felt good. I've been building for 6 weeks now without stopping." |
| **Feelings** | Proud, accomplished (5/5) |
| **Pain Point** | If milestones don't feel meaningful, checking them off loses significance |
| **Opportunity** | Milestone completion triggers a brief AI reflection: "You said this would take 4 weeks. You did it in 3. What changed?" |

---

### Phase 5: Referral

**Context:** Alex's friend is going through a career transition and asks what Alex is using to "stay so focused."

| Dimension | Detail |
|-----------|--------|
| **Actions** | Shares SOC referral link; explains the Discovery Session concept |
| **Thoughts** | "I want her to have the same experience I had." |
| **Feelings** | Enthusiastic, helpful (5/5) |
| **Pain Point** | No referral incentive currently exists |
| **Opportunity** | Implement referral program: "Give a friend 1 free month, get 1 free month" |

## Journey Summary: Emotion Arc

```
Acquisition → Onboarding → First Session → Aha Moment → Habit Loop → Milestone → Advocacy

Emotion:
5 |                                      ★ Aha Moment           ★ Milestone
4 |            ★ Demo                  ↗                  →           ↗     ★ Referral
3 |  ★ Aware      → Sign-Up → Session ↗   Daily Check-ins
2 |
1 |
  ├──────────────────────────────────────────────────────────────────────────────
  Awareness  Consideration  Sign-Up  First Session  Week 2+  Milestone  Advocacy
```

**Critical moments to get right:**
1. The demo video (first impression)
2. The first AI question in Discovery Session
3. The generated project (first output quality)
4. The "first task" prompt immediately after Aha moment
