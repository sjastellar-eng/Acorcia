## 1. Brand Identity

### 1.1 Brand Essence

Source Constructor is a platform that helps people uncover their true desires and build structured paths toward them. The brand embodies:

- **Clarity** — cutting through noise to reveal what truly matters
- **Momentum** — turning insights into consistent daily action
- **Intelligence** — AI that feels like a thoughtful human companion
- **Warmth** — technology that feels human, not clinical

### 1.2 Brand Positioning

> *"The AI companion that helps you discover what you truly want — and build it."*

**Tagline:** *Know what to build. Build what matters.*

### 1.3 Brand Personality

| Trait | Description |
|-------|-------------|
| Thoughtful | Asks deep questions, listens carefully |
| Empowering | Builds confidence, not dependency |
| Clear | Communicates with precision and brevity |
| Warm | Human-centered, never robotic |
| Ambitious | Helps users think bigger |

## 2. Logo

### 2.1 Logo Concept

The SOC logo combines two visual elements:
- A **source point** (circle/dot) representing origin and clarity
- An **arrow or path** representing forward motion and construction

### 2.2 Logo Variants

```
Primary Logo:     ● Source Constructor
Compact Logo:     ● SOC
Icon Only:        ●
```

### 2.3 Clear Space

Minimum clear space around the logo = 1× the height of the "S" in "Source".

### 2.4 Logo Don'ts

- Do not stretch or distort the logo
- Do not change logo colors outside approved palette
- Do not place on low-contrast backgrounds
- Do not add effects (shadows, gradients, outlines)

### 4.1 Type Scale

**Primary Typeface:** Inter (Google Fonts)
**Monospace:** JetBrains Mono (for code blocks)

| Level | Size | Weight | Line Height | Usage |
|-------|------|--------|-------------|-------|
| Display | 48px / 3rem | 700 | 1.1 | Hero headlines |
| H1 | 36px / 2.25rem | 700 | 1.2 | Page titles |
| H2 | 28px / 1.75rem | 600 | 1.3 | Section headers |
| H3 | 22px / 1.375rem | 600 | 1.4 | Sub-section headers |
| H4 | 18px / 1.125rem | 600 | 1.4 | Card titles |
| Body Large | 18px / 1.125rem | 400 | 1.7 | Lead text, intros |
| Body | 16px / 1rem | 400 | 1.6 | Default body text |
| Body Small | 14px / 0.875rem | 400 | 1.5 | Captions, labels |
| Caption | 12px / 0.75rem | 500 | 1.4 | Metadata, timestamps |

### 4.2 Typography Rules

- Never use more than 3 type sizes on a single screen
- Line length: 60–75 characters for body text
- Minimum body text size: 14px
- Heading hierarchy must be sequential (no skipping H2 → H4)

## 7. Illustration & Photography

### 7.1 Illustration Style

- Abstract, geometric shapes with rounded corners
- Use brand colors only (Cobalt, Lavender, Navy)
- Avoid literal representations — prefer metaphorical
- Consistent stroke weights

### 7.2 Photography Guidelines

- Real people in thoughtful, focused states
- Environments: home office, café, outdoors
- Lighting: natural, warm
- Avoid: stock photo clichés, overly posed shots

## 8. Voice & Tone

### 8.1 Brand Voice

| Dimension | We Are | We Are Not |
|-----------|--------|------------|
| Tone | Warm, encouraging | Cold, transactional |
| Language | Clear, direct | Jargon-heavy |
| Attitude | Curious, open | Prescriptive, judgmental |
| Energy | Calm confidence | Hype, urgency |

### 8.2 Writing Principles

1. **Start with the user's reality** — acknowledge where they are now
2. **Use "you" language** — make it personal and direct
3. **Active voice always** — "Build your project" not "Your project will be built"
4. **Short sentences** — average 15 words maximum
5. **No jargon** — if you can't say it simply, rethink it

### 8.3 Sample Copy

**Good:** "You've completed your first Discovery Session. Here's what we learned about you."

**Avoid:** "Congratulations! Our proprietary AI system has successfully processed your input data and generated personalized insights based on your responses."

## 9. UI Motion Principles

- **Purposeful:** motion conveys meaning, not decoration
- **Fast:** transitions < 200ms, complex animations < 400ms
- **Subtle:** ease-in-out curves, no bouncing
- **Respectful:** respect `prefers-reduced-motion` media query

### 9.1 Standard Easing

```css
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
--ease-enter: cubic-bezier(0, 0, 0.2, 1);
--ease-exit: cubic-bezier(0.4, 0, 1, 1);
```

## 10. Accessibility Standards

- **WCAG 2.1 AA** compliance minimum
- Color contrast ratio: ≥ 4.5:1 for normal text, ≥ 3:1 for large text
- All interactive elements have `:focus-visible` styles
- All images have descriptive `alt` text
- All form inputs have associated `<label>` elements
- Keyboard navigation must work for all interactive elements
